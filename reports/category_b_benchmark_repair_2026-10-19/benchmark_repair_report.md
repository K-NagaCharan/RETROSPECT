## 4. Hard Negatives Population & Distractor Discrimination

To test whether Retrospect can discriminate the true historical successor from confusing competitors, 2 distractors were mined per case:

1. **`same_file_adjacent` (Primary Distractor):**
   - Declared in the exact same class as the target symbol at the evaluation pin commit.
   - Example (`CASE-HIST-JAVA-0020`, `Violation.java`): Target is `getCustomViolation`. Distractors are `getLineNo` and `getSeverityLevel` (coordinate and severity accessors sharing enclosing class tokens).
   - Example (`CASE-HIST-JAVA-0105`, `PrepareRoutingSubnetworks.java`): Target is `markNodesRemovedIfUnreachable`. Distractor is `keepLargeNetworks` (adjacent subnetwork filtering method).
2. **`structural_sibling` (Secondary Distractor):**
   - Declared in sibling classes within the same package or pipeline handling related data structures.
   - Example (`CASE-HIST-JAVA-0034`, `ArrayBackedRow.java`): Target is `getValue`. Distractor is `getType` (data type metadata accessor) and `getColumnDefinitions` (column schema accessor).
